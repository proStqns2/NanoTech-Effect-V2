# NanoTech Effect V2 — Iron Man Mark LXXXV (Webcam Temps Réel)

Expérience **webcam plein écran** qui détecte automatiquement votre **corps entier, votre tête et vos deux mains** en temps réel (MediaPipe Pose Full + Face Mesh 478 points + Hands) et équipe directement sur vous l'armure **Iron Man Mark LXXXV (Mark 85)** complète grâce à l'effet de génération **nanotechnologie en métal liquide** partant de l'Arc Reactor thoracique (basé sur la méthode shader de [Cartesian Caramel](https://youtu.be/eI2p6hNi6w8)).

## Fonctionnement

1. Ouvrez l'application (HTTPS ou `http://localhost:5173`) et autorisez la webcam : la caméra s'affiche immédiatement en plein écran.
2. Placez-vous face à votre caméra : l'**Arc Reactor** se verrouille sur votre torse et l'armure Mark 85 complète (torse, abdos, épaules, cou, casque, masque doré, bras, avant-bras, gantelets, 30 phalanges articulées, bassin, cuisses, genouillères, tibias et bottes) se matérialise en métal liquide sur votre corps.
3. **Gestes naturels** :
   - **Touchez votre torse (Arc Reactor)** pendant une demi-seconde pour rétracter l'armure ou la redéployer.
   - **Ouvrez la paume face à la caméra** pour charger et déclencher les répulseurs palmaires.
4. **Raccourcis rapides** : `Espace` / `R` (rejouer l'effet nanotech), `E` (rétracter/équiper), `V` (ouvrir/fermer le masque doré sur votre visage), `M` (son), `F` (plein écran).

## Lancement local

```bash
npm install
npm run dev
```

Puis ouvrez `http://localhost:5173`.
